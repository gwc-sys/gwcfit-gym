# Website build prompt

Create a premium, responsive React marketing website for **PulseFit**, an AI-powered gym operating system. The primary audience is independent gym owners and multi-location fitness businesses—not gym members. The website must quickly explain what PulseFit does, how it works, and how it helps a gym improve retention, revenue, staff efficiency, and member experience.

Use a fresh visual direction that is clearly different from the existing dark-purple SaaS dashboard: warm ivory background, near-black typography, electric lime accents, editorial layouts, oversized headlines, strong borders, subtle grain, rounded product cards, and restrained motion. The tone should be direct, confident, practical, and human.

Build these sections:

1. Sticky navigation with Product, How it works, Results, login, and demo CTA.
2. Hero focused on the outcome: “Run your gym. Grow your people.” Include a realistic dashboard preview and proof metrics.
3. A pain-to-outcome strip that frames scattered gym operations as one connected system.
4. An interactive feature explorer covering member CRM, attendance, trainer workflows, payments, AI workout/diet plans, and reports.
5. A three-step “How PulseFit works” section: set up, operate, improve.
6. A gym improvement section showing retention, time saved, and revenue visibility.
7. Testimonials and trust signals.
8. A high-conversion demo CTA and complete footer.

Also include the full member lifecycle (onboarding, QR attendance, training, nutrition/goals, payments and renewal), explain the different workspaces for owners, receptionists, trainers, members and platform admins, and add detailed Launch, Grow and Scale pricing. Promote a 30-day free trial on every plan with no credit card required.

Requirements: React only, no backend; clean reusable components; responsive from mobile through desktop; accessible keyboard controls and semantic HTML; sticky nav, mobile menu, interactive feature tabs, subtle reveal animation, and buttons that scroll to the demo form. Avoid generic fitness clichés, excessive gradients, glassmorphism, and stock-template layouts.
